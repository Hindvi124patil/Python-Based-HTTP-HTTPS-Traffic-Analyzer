TShark Architecture: NetScope utilizes TShark (Wireshark's headless packet dissection tool) for fast deep-packet inspection of binary .pcap and .pcapng captures. If TShark is not detected, NetScope gracefully falls back to native Python Scapy dissection.

How to Capture & Export in Wireshark

Step-by-Step
  1. Open Wireshark on your Windows machine and choose your active Network Interface (e.g., Wi-Fi or Ethernet).
  2. Apply capture filter: tcp port 80 or tcp port 443 or udp port 53 or udp port 443.
  3. Open your web browser and visit web pages (e.g., http://example.com or https://github.com).
  4. Stop packet capture in Wireshark (red square button).
  5. Save as PCAP/PCAPNG: Go to File → Save As... and save as capture.pcapng.
  6. Export as CSV: Go to File → Export Packet Dissections → As CSV... and save.
  7. Upload the generated file into NetScope above!

Network Security & Encryption Explanation

Understanding why HTTPS and QUIC application data cannot be read in plaintext

RFC 8446 • TLS 1.3

In modern computer networks, HTTPS utilizes Transport Layer Security (TLS 1.2 / TLS 1.3), while HTTP/3 operates over QUIC (UDP 443) with integrated TLS encryption. During packet capture:

Visible Metadata
  • Ethernet MAC addresses & IP addresses
  • TCP & UDP communication ports (e.g., 443, 80)
  • Packet lengths, timing, and sequence numbers
  • TLS Client Hello: Cipher suites & Server Name Indication (SNI)
Protected / Encrypted
  • HTTP Request URLs, Paths, and Query strings
  • HTTP Headers (Cookies, Authorization tokens)
  • HTTP Request & Response Body (HTML, JSON, Images)
  • Session Keys (symmetric AES-256-GCM / ChaCha20)
Academic Viva Note: NetScope strictly adheres to academic principles and computer networking ethics. It analyzes network layer packets, transport handshakes, and protocol flow without attempting unauthorized cryptographic decryption. To inspect decrypted HTTPS payload in a laboratory setting, one must supply session keys generated via the SSLKEYLOGFILE environment variable.

About NetScope — HTTP/HTTPS Traffic Analyzer

Computer Networks Academic Project • Department of Computer Engineering

5 Objectives Verified

Project Abstract

NetScope is a comprehensive, functional, beginner-friendly Computer Networks academic tool designed to inspect, dissect, and visualize modern Web traffic. Built with Python 3, Flask, pandas, numpy, and Chart.js, NetScope processes both binary packet captures (PCAP/PCAPNG) using Wireshark's TShark engine and Wireshark-exported CSV traces. It provides clear insights into cleartext HTTP (TCP 80), encrypted HTTPS / TLS (TCP 443), and next-generation QUIC / HTTP/3 (UDP 443) protocols.
