# NetScope — Python-Based HTTP/HTTPS Traffic Analyzer

## 📌 Project Overview
NetScope is a Python-based web application developed for the Computer Networks subject. It analyzes network traffic using Wireshark and TShark and presents packet details, protocol statistics, and traffic visualizations through an interactive dashboard.

## 🎯 Objectives
- To analyze HTTP/HTTPS-related network traffic.
- To identify source and destination IP addresses and protocols.
- To examine packet sizes and network activity.
- To visualize traffic statistics using graphs.
- To generate reports for network traffic analysis.

## ✨ Features
- Interactive dashboard
- Packet and protocol analysis
- HTTP/HTTPS-related traffic insights
- Traffic graphs and statistics
- Network capture file upload
- CSV and JSON report export

## 🛠️ Technologies Used
- Python and Flask
- Wireshark and TShark
- Pandas and NumPy
- HTML, CSS, and JavaScript
- Chart.js

## 🚀 How to Run
1. Install Python and Wireshark with TShark.
2. Install the required Python dependencies.
3. Run the application:

```bash
python app.py
```

4. Open `http://127.0.0.1:5000` in your browser.
